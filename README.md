# Human-Computer Interaction & Data Visualization
**Studi kasus:** dashboard ringkas untuk memantau pendapatan toko.

**Jalankan:** `streamlit run app.py`.

Dashboard memiliki filter produk dan tanggal, tiga metrik utama, grafik batang, grafik tren, dan tabel transaksi. Data transaksi dibuat sintetis untuk demonstrasi.

## Instalasi

Gunakan Python 3.10 atau lebih baru. Dari folder repository, jalankan:

```bash
python -m venv .venv
```

Aktifkan lingkungan virtual:

- Windows: `.venv\Scripts\activate`
- Linux/macOS: `source .venv/bin/activate`

Pasang dependensi:

```bash
pip install -r requirements.txt
```

## Catatan

Lihat deskripsi studi kasus di atas sebelum menjalankan program. Jika `requirements.txt` kosong, program hanya memakai pustaka bawaan Python.
